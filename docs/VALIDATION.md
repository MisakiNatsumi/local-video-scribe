# 验证范围与速度说明

验证环境：Windows、RTX 5080 16 GB、faster-whisper 1.2.1、CTranslate2 4.8.5。

| 测试 | 设置 / 结果 |
| --- | --- |
| 10 分钟测试视频 | 重复英文合成语音，turbo、FP16、batch size 16 |
| 音轨提取和推理 | 约 27.31 秒 |
| 包含模型加载的工作进程总用时 | 约 30.04 秒，即约 20 倍播放速度 |
| 覆盖检查 | 最后转写时间戳到达 600 秒，检查了开头和结尾文字 |
| 多文件处理 | 两个不同目录中的同名视频分别生成 TXT / SRT / JSON |
| 重复运行 | 已完成且来源、模型、语言匹配的文件被跳过 |
| 异常输入 | 损坏视频报告失败后继续处理后续文件 |
| 便携性 | 从 ZIP 另行解压到含中文和空格的目录，测试进程 PATH 仅含 System32 |
| 离线模型 | 禁用 Hugging Face 联网下载后，从内置模型完成 GUI 批处理 |
| CPU 模式 | 强制 CPU 后端处理短样本，成功导出结果 |

该素材是合成语音重复构成的功能和吞吐样本，不代表真实课堂、不同语言或噪声环境下的性能。
没有对真实课程建立字错率 / 词错率基准，也没有在另一台干净 Windows 机器上完整验证。

“高倍速”表示具备通过 GPU 批处理显著快于播放速度的能力，不是任何硬件、模型、语言和素材下的保证。
首次模型下载、CUDA 初始化、语言、语速、静音比例、其他显存占用都会影响耗时。

建议先用实际课程的 10～20 分钟片段测量，再估算全批任务。
